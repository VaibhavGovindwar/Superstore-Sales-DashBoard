# 📊 Superstore Sales Analysis Dashboard (Power BI)

## 🔍 Project Overview
Developed an interactive Power BI dashboard to analyze retail sales performance using the Superstore dataset. The dashboard provides insights into sales trends, product performance, regional distribution, and customer segmentation.

## 📁 Dataset
- Records: ~760+
- Features: 8 key input features (Category, Sub-Category, Region, Segment, Sales, Profit, Quantity, Order Date)

## 📊 Key Insights
- 📈 Achieved ~86% identification of high-performing categories based on sales contribution
- 💻 Technology category contributed ~35–40% of total profit
- 🌎 West region generated the highest revenue (~30%+ of total sales)
- 👥 Consumer segment accounted for ~50% of overall sales
- 📦 Top 10 products contributed ~40% of total revenue

## 🛠 Tools & Technologies
- Power BI
- Excel (Data Cleaning)
- Data Visualization Techniques

## 📌 Features
- Interactive slicers (Region, Category, Segment, Date)
- Sales & profit trend analysis
- Regional performance mapping
- Top product identification
